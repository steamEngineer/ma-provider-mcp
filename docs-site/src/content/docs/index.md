Provider created and maintained by [TrudenBoy](https://github.com/TrudenBoy).




## Setup


Setup instructions are on the [Configuration](configuration/) page.


## Quick connect

After enabling the plugin, click **Open Connect Wizard** in the
provider's settings panel. Pick your AI client — the wizard mints a
per-client token (`MCP — <Client>`, individually revocable in
Settings → Security → Tokens) and shows the ready-to-paste snippet.
Cursor users get an **Add to Cursor** one-click deeplink. Supports
Claude Desktop, Claude Code, Cursor, Windsurf, VSCode (Copilot Chat),
ChatGPT (Connectors), Codex CLI, Gemini CLI, Cline, and Zed.
